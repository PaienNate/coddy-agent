# 粘贴并标注图片

你复制的一张图片 —— 一张截图、来自查看器或浏览器的图像、在文件管理器中复制的图像文件 —— 可以通过粘贴放进提示词，在控制台和 Web 界面中都可以。在附加之前，图片会先在标注编辑器中打开，你可以在其中圈出关键部分、用箭头指向它，并在旁边写上一个词。控制台把编辑器作为桌面上的窗口打开，Web 界面则在聊天之上打开它；两者的工具和按钮完全相同。

图片只会送达接受图片的模型，即其 `models` 行上带有 `multimodal: true` 标记的模型（[Images](images.md#能读取图片的模型)）。

## 在控制台中

在控制台中按 **ctrl+v** 粘贴剪贴板中的图片。终端只能粘贴文本，因此 Coddy 会向桌面请求图片本身：

| 桌面 | 图片的来源 |
|---|---|
| X11，或带 XWayland 的 Wayland | X 剪贴板，由 Coddy 自身通过 X 协议读取；不需要 `xclip` |
| Wayland | 安装了 wl-clipboard 时使用 `wl-paste`，否则在 XWayland 运行时使用 X 剪贴板 |
| macOS | `osascript`，每台 Mac 都有 |
| Windows | PowerShell |

剪贴板提供的 PNG、JPEG、WebP、GIF、BMP 或 TIFF 图片会被采用；BMP 和 TIFF 会转换为 PNG，因为提供商不接受这两种格式。在文件管理器中复制的图像文件会按其路径读取。大于 50 MB 的图片，或文件头声明超过 4000 万像素的图片，会在解码像素之前被拒绝，并给出原因；剪贴板所有者 15 秒内未响应的，会按此报告。当终端把 ctrl+v 保留给自身的粘贴功能时（如 Windows Terminal），请按 **alt+v**。

图片在编辑器中以标记的形式出现，而包含该标记的提示词则携带这张图片：

```text
what is circled here? [image #1]
```

退格键会将标记作为整体删除，图片也随之删除。标记文本也会传给模型，因此带有多个图片的提示词可以说明指的是哪一张。用上箭头从历史中调出的提示词会重新附加其图片，前提是它们仍在最近粘贴的 32 张之内。在轮次运行期间粘贴的图片会随你排队的消息一起发送（[Message queue](message-queue.md)）。

控制台没有图片显示能力，因此它会以文本形式列出提示词携带的每一张图片：图片显示为 `[image #N]`，其他文件显示为 `[file: name]`。从 Web 界面或带图片的 Telegram 聊天发送的提示词，在控制台中同样显示为 `[image #1] describe it`。会话会连同其资源一起保存每一张图片，因此 Web 界面会把在控制台中粘贴的图片显示为图片，点击即可全尺寸打开：

![Web 界面显示在控制台中输入的提示词：粘贴的图表以预览卡片显示在气泡 "[image #1] which node backs up here?" 之上，下面是回答](../../assets/picture-markup/console-paste-in-web-dark-1280.png)

*在控制台中粘贴的一张图片，显示在 Web 界面中。*

当剪贴板中不含图片时，控制台会说明这一点；当会话的模型未标记 `multimodal`，或在 `models` 中没有对应行时，会拒绝粘贴；当会话切换到此类模型时，标注窗口中尚未确认的图片也不会被附加。在 `--remote` 上，由服务器决定哪些模型接受图片。

## 标注窗口

![标注窗口覆盖在粘贴的截图之上：一个椭圆、一个箭头和一个红色标签，底部是工具和调色板](../../assets/picture-markup/console-markup-window-dark-1280.png)

*控制台的标注窗口在 X 显示上。*

当环境指定了 X 显示（设置了 `DISPLAY`：X11 会话、带 XWayland 的 Wayland、Mac 上的 XQuartz、通过 `ssh -X` 转发的显示），粘贴的图片会在附加之前于窗口中打开。**Done** 会附加标注后的图片，**Cancel** 则不附加任何内容。关闭窗口也等同于 Cancel。窗口打开期间控制台仍可正常工作，点击 Done 后标记会出现在编辑器中。

该窗口由 Coddy 自身通过 X 协议绘制，不使用任何 GUI 库，因此同一个静态二进制文件在任何可达 X 服务器的地方都能打开它。没有 X 显示时 —— 纯 Wayland 会话、未装 XQuartz 的 macOS、Windows、远程 shell —— 图片会按复制时的原样附加。当显示存在但窗口无法打开时，控制台会说明原因，并同样按原样附加图片。

| 工具 | 按键 | 拖动时执行的操作 |
|---|---|---|
| 铅笔 | `p` | 沿着指针绘制一条线 |
| 椭圆 | `o` | 在拖出的方框内绘制椭圆轮廓 |
| 矩形 | `r` | 绘制矩形轮廓 |
| 箭头 | `a` | 从拖动起点到终点绘制一个箭头 |
| 文本 | `t` | 单击即可在该处放置标签；输入内容，Enter 完成，Escape 丢弃 |
| 裁剪 | `c` | 保留拖出的方框内的图片部分 |

工具栏还可以将图片顺时针旋转四分之一圈，并撤销上一步：一个形状、一个标签、一次裁剪或一次旋转。裁剪不会造成任何损失，因为撤销会重放原始图片。七种颜色为红、橙、黄、绿、蓝、白和黑；线条宽度和标签大小随图片尺寸而定。在未输入标签时，**Enter** 是 Done，**Escape** 是 Cancel，**ctrl+z** 是撤销。标签按当前生效的键盘布局输入，包括俄语等第二布局，而快捷键按物理按键生效：`r` 和 ctrl+z 在俄语布局以及开启大写锁定时仍然有效。窗口会跟随桌面的缩放比例（`Xft.dpi`）。

## 在 Web 界面中

![Web 界面中的标注编辑器覆盖在粘贴的图表之上：一个椭圆、一个箭头、一个标签和一个矩形，底部是工具和调色板](../../assets/picture-markup/web-markup-editor-dark-1280.png)

*Web 界面中的标注编辑器。*

粘贴到输入框中的一张图片会在聊天之上打开同一个编辑器。**Done** 会将其作为以粘贴命名的 PNG 附加（`pasted-1.png`），**Cancel** 或 **Escape** 则不附加任何内容。工具、按键和颜色与上表一致，按键按其键盘位置生效，与控制台相同；**Ctrl+Z** 或 **⌘Z** 撤销上一步。在工具栏中聚焦某个按钮时按 Enter 会按下该按钮，Tab 会停留在编辑器内部。

使用触控笔时 —— Surface Pen、Apple Pencil、绘图板 —— 铅笔会按下压力越大画得越粗，保留笔报告的每一个点，因此快速画出的线条仍然圆润，并在笔使用时忽略搁在屏幕上的手。鼠标和手指仍按单一宽度绘制，与之前一样。控制台的窗口不支持压感。

通过回形针附加、拖入输入框或与其他图片一起粘贴的图片会立即附加。其卡片左上角的铅笔会将其在编辑器中打开：Done 会用它替换为标注后的副本，Cancel 则保持原样。无法在画布上绘制的浏览器会立即附加粘贴的图片，并且不显示铅笔。编辑器的代码会在第一次打开图片时加载；当无法加载时（例如标签页在更新期间一直开着），粘贴的图片会按原样附加。

## 发送的内容

Done 会把当前的图片转换为 PNG：绘制的标记被画入其中，并按你留下的状态裁剪和旋转。未经编辑器附加的图片会按复制时的原始格式发送。无论哪种方式，从此它就是一张普通的附件：会话会连同其资源一起保存它，并适用 [Images](images.md#发送给模型的内容) 中的限制。
